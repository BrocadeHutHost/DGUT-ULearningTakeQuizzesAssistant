## 功能特性

- **课程签到监测**：自动读取课程列表，轮询当日课堂活动，命中进行中的签到后自动提交。数字码签到、一键签到可直接完成；二维码签到仅当活动数据自带签到码时才处理（脚本不识别教室现场二维码图片）。
- **视频自动倍速播放**：突破网页播放器限制，支持自定义倍速（默认 6 倍），自动静音防拦截，倍速守卫抗平台回退，看完自动翻页。
- **全自动答题**：支持单选、多选、判断、填空、简答、选词填空、排序等题型自动作答与提交。答案源优先级：页面视图模型 → 本地题库 → 接口。未知题型一律跳过，绝不盲点。
- **本地题库沉淀**：答题时自动将题目及正确答案缓存至浏览器本地，支持一键导出为 Word 文档复习。
- **作业互评汇总**：在互评详情页读取互评接口，去匿名化评价人，汇总记录并支持按姓名/学号/分数筛选。
- **求是读书**：按书目累计真实阅读时长（与服务端 KO 视图模型同步），满 4h10m 自动翻页/切书；阅读器 iframe 由父窗口 postMessage 驱动自动翻页。
- **文档工具**：Markdown 一键转 Word（.doc）/ PDF（打印视图）；内置手绘电子签名画板，支持鼠标/触屏/触控笔，可保存多份签名并附加到导出文档末尾。
- **双主题切换**：浅色/深色/跟随系统三种模式，六种预设主体色 + 自定义颜色，面板支持任意拖拽并记忆上次位置。
- **安全防护**：内置防页面移除机制，保护答题面板不被平台反作弊脚本清除；文档处理全部在浏览器本地完成，内容不上传任何服务器。

## 安装指南

1. **安装浏览器插件**：
   在你的浏览器（Chrome/Edge/Firefox 等）中安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）或 [Violentmonkey](https://violentmonkey.github.io/)（暴力猴）插件。
2. **添加脚本**：
   点击浏览器右上角的油猴图标，选择“添加新脚本”或“创建新脚本”，将本脚本的完整代码粘贴进去。
3. **保存并启用**：
   按 `Ctrl + S` 保存脚本，确保脚本处于“已启用”状态。
4. **访问目标网站**：
   打开优学院或 DGUT 相关的学习页面，页面右下角会出现悬浮图标，点击即可展开操作面板。

## 使用说明

### 基础面板操作

- **拖拽面板**：按住面板顶部的标题栏（“优学院助手 + 文档工具”区域）即可将面板拖动到屏幕任意位置。
- **切换主题**：点击侧栏的“外观设置”，可在浅色、深色、跟随系统之间切换，并选择主体色。
- **查看详情**：点击侧栏的“关于/帮助”，可查看脚本版本、作者、开源许可 (AGPL-3.0-only) 及功能说明。

### 课程签到

进入优学院任意页面，打开面板侧栏的“课程签到”：

1. **读取课程**：点击“读取课程”按钮，脚本会拉取你已选课程列表。
2. **选择课程**：在列表中点击要监测的课程（支持搜索名称/教师/ID）。
3. **设置参数**：可调整轮询间隔（默认 5 秒）、签到定位经纬度与地址。
4. **开始监测**：点击“开始监测”，脚本会按间隔轮询当日课堂活动，发现进行中的签到即自动提交。
5. **查看日志**：下方运行日志会实时显示签到结果；可导出 Markdown 格式的签到记录。

> 注意：二维码签到仅当活动数据本身包含签到码时才会自动处理，否则会明确跳过并记录原因。

### 刷课助手

进入包含视频的课件页（地址含 `ua.dgut.edu.cn/learnCourse`），打开面板侧栏的“刷课助手”：

1. **设置参数**：视频倍速（默认 6，建议 6~10）、是否自动答题、是否自动翻页、是否收集题库。
2. **启动**：点击“启动”按钮，脚本将自动以设定倍速播放视频，并在遇到题目时尝试作答。
3. **导出题库**：答题过程中题目及答案会自动缓存；点击“导出题库”可导出为 Word 文档复习。
4. **清空题库**：点击“清空题库”可清除本地缓存（不可逆）。

> 安全说明：未知题型一律跳过、绝不盲点（平台测验多为“限答 1 次”）。答案优先取页面视图模型，其次本地题库，最后请求答案接口。

### 作业互评

进入作业互评详情页（URL 含 `stuDetail/学号/作业ID`），打开面板侧栏的“作业互评”：

1. **扫描当前作业**：点击“扫描当前作业”，脚本会读取互评接口并去匿名化评价人信息。
2. **查看记录**：记录以卡片形式展示评价人、分数、评语、班级与时间。
3. **筛选**：可按评价人姓名/学号筛选，或按分数区间（如 `80-95`、`>90`）筛选。
4. **清空记录**：点击“清空记录”可清除本地保存的所有互评记录。

### 求是读书

进入求是读书课件页（地址含 `ua.dgut.edu.cn/learnCourse/learnCourse.html`），打开面板侧栏的“求是读书”：

1. **开始/暂停**：点击“开始”后脚本开始累计阅读时长；点击“暂停”停止统计。
2. **翻页间隔**：可设置阅读器自动翻页的秒/页（默认 30 秒），保存后同步给 iframe 阅读器。
3. **同步服务端**：点击“同步服务端”可将服务端记录的时长同步到本地。
4. **自动切书**：累计时长满 4 小时 10 分钟后，脚本会自动翻页并切换下一本书。

### 文档工具

打开面板侧栏的“文档工具”：

1. **输入 Markdown**：在文本区输入或粘贴 Markdown 内容（支持标题、粗体、列表、代码块、表格、引用等）。
2. **预览**：点击“预览”按钮可实时查看渲染效果。
3. **导出 Word**：点击“导出 Word”生成 `.doc` 文件（HTML 内容承载），Word / WPS 可直接打开与二次编辑。
4. **导出 PDF**：点击“导出 PDF”打开打印视图，在打印对话框中选择“另存为 PDF”即可。
5. **手绘电子签名**：
   - 在画板上手写签名（支持鼠标 / 触屏 / 触控笔）。
   - 填写签名标签（如“本人签名”“导师签字”），点击“保存签名”。
   - 已保存的签名以缩略图展示，勾选后会自动附加到导出文档末尾。
   - 签名以透明 PNG 形式嵌入，可删除或重新绘制。

### 外观设置

打开面板侧栏的“外观设置”：

- **主题模式**：亮色 / 暗色 / 跟随系统。
- **主体色**：紫罗兰、蔚蓝、松石、青绿、琥珀、玫红六种预设，也可使用取色器自定义颜色。
- 设置自动保存并立即生效。

### 调试与日志

- 签到模块与刷课模块均自带运行日志窗口，实时显示接口请求、签到/答题结果与报错信息。
- 遇到问题时，可复制日志内容一并提交 issue。

## 常见问题 (FAQ)

**Q: 签到监测没反应？**
A: 请先确认已登录优学院，且所选课程当天有课堂活动。检查轮询间隔是否设置过短或网络是否正常。若仍无反应，查看运行日志中的报错信息。

**Q: 二维码签到为什么总是跳过？**
A: 脚本不会识别教室现场展示的二维码图片。二维码签到仅当活动数据本身已包含签到码时才会自动处理，否则会明确跳过并记录原因。

**Q: 刷课倍速设置后没有生效？**
A: 部分浏览器对超过 16 倍速有硬性限制，建议将倍速控制在 6 到 10 之间。另外，请确保你点击了“启动”按钮启动脚本的监控逻辑。

**Q: 自动答题会盲点吗？**
A: 不会。未知题型一律跳过、绝不盲点。平台测验多为“限答 1 次”，脚本会优先取页面视图模型，其次本地题库，最后请求答案接口。

**Q: 文档导出 Word 打不开？**
A: 生成的是 `.doc` 文件（HTML 内容承载），Word / WPS 均可打开。若提示格式问题，可尝试用 WPS 打开或另存为 `.docx`。PDF 请使用打印对话框中的“另存为 PDF”。

**Q: 签名会丢失吗？**
A: 签名保存在浏览器本地存储中。清除浏览器数据或更换设备会导致签名丢失，重要签名建议导出文档后另行保存。

**Q: 脚本面板不小心被拖到屏幕外找不到了怎么办？**
A: 在 Tampermonkey 的脚本管理界面中，使用本脚本的菜单命令“重置面板/悬浮面板位置”，即可恢复默认位置。
