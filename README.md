## 功能特性

- **视频自动倍速播放**：突破网页播放器限制，支持自定义倍速（默认6倍），自动静音防拦截，看完自动翻页。
- **全自动答题**：支持单选、多选、判断、填空、简答、选词填空、排序等全题型自动作答与提交。
- **在线题库查询**：一键查询当前页面所有题目答案，支持点击答案一键复制。
- **本地题库沉淀**：答题时自动将题目及正确答案缓存至浏览器本地，支持一键导出为 Word 文档复习。
- **双主题切换**：浅色/深色主题自由切换，面板支持任意拖拽，记忆上次位置。
- **安全防护**：内置防页面移除机制，保护答题面板不被平台反作弊脚本清除。

## 安装指南

1. **安装浏览器插件**：
   在你的浏览器（Chrome/Edge/Firefox等）中安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）或 [Violentmonkey](https://violentmonkey.github.io/)（暴力猴）插件。
2. **添加脚本**：
   点击浏览器右上角的油猴图标，选择“添加新脚本”或“创建新脚本”，将本脚本的完整代码粘贴进去。
3. **保存并启用**：
   按 `Ctrl + S` 保存脚本，确保脚本处于“已启用”状态。
4. **访问目标网站**：
   打开优学院或 DGUT 相关的学习页面，页面左上角（或右上角）即可看到悬浮的操作面板。

- **拖拽面板**：按住面板顶部的标题栏（“DGUT 优学院助手”区域）即可将面板拖动到屏幕任意位置。
- **切换主题**：点击标题栏右侧的太阳/月亮图标，可在浅色和深色主题之间切换，设置将自动记忆。
- **查看详情**：点击标题栏右侧的 `i` 图标，可查看脚本版本、作者、开源许可 (AGPL-3.0) 及免责声明。

### 视频自动学习

进入包含视频的课程页面时，面板会自动显示视频控制区：

1. **开始视频**：点击“开始视频”按钮，脚本将自动以设定的倍速播放视频。若视频被暂停，脚本会自动尝试恢复播放。
2. **暂停视频**：点击“暂停视频”可停止自动播放逻辑。
3. **调整倍速**：在输入框中输入你想要的倍速数值（如 `10`，最高取决于浏览器和设备性能，建议不超过 `16`），然后点击开始视频。脚本会强制覆盖原生播放器的倍速。

### 自动答题与题库查询

进入作业或考试页面时：

1. **查询答案**：点击“查询答案”按钮，脚本会抓取当前页面的所有题目，并向题库服务器发起查询。查询到的答案会显示在下方的列表中。
2. **点击复制**：点击列表中的题目或答案，可一键将答案复制到剪贴板。
3. **自动作答**：在支持自动作答的页面（如练习模式），脚本在查询到答案后会自动将答案填入对应的选项或输入框中，并自动点击提交。若题库未命中，会显示“未命中(已回传)”，并将你的题目匿名上传至题库以供后续补充。

### 题库导出与管理

所有你在做题时遇到的题目及正确答案，都会自动保存在浏览器本地：

1. **导出当前页**：将当前正在浏览的这一页题目及答案导出为 Word 文档（.doc 格式）。
2. **导出累计**：将你历史上在本课程刷过的所有题目及答案汇总导出为一个 Word 文档，非常适合期末复习。
3. **清空题库**：清空当前浏览器中存储的所有本地题库数据（此操作不可逆，请谨慎点击）。

### 调试与日志

1. **显示/隐藏日志**：点击“显示日志”按钮，会在面板底部展开一个调试日志窗口，实时显示脚本的运行状态、接口请求结果和报错信息。
2. **复制日志**：点击“复制日志”按钮，可将所有的调试日志复制到剪贴板，方便在寻求技术支持时提供给开发者。

## 常见问题 (FAQ)

**Q: 提示“IP受限(E403或E503)”或查询不到答案怎么办？**
A: 题库服务器为了防止滥用，可能会对免费 IP 进行限制。你可以通过点击提示获取 Token，输入授权码以提升稳定性。如果没有 Token，请稍后再试或通过正常做题积累贡献。还有一种可能是当前页面没有题目但是你点击了获取答案，显示如下：

**Q: 视频倍速设置后没有生效？**
A: 部分浏览器对超过 16 倍速有硬性限制。建议将倍速控制在 `6` 到 `10` 之间（Microsoft edge浏览器实测最高支持16倍速，在校园网环境下10倍速，超过可能带来无法播放和卡顿，重新设计即可恢复）。另外，请确保你点击了“开始视频”按钮启动脚本的监控逻辑。

**Q: 脚本面板不小心被拖到屏幕外找不到了怎么办？**
A: 脚本会自动记忆面板的位置。你可以在 Tampermonkey 的脚本管理界面，编辑本脚本，寻找并修改位置相关的代码，或者在浏览器的开发者工具中手动删除记录位置的 localStorage 项。

**Q: 自动答题时部分题目没有自动提交？**
A: 优学院页面结构复杂且经常变动，部分特殊题型（如综合题、语音题）可能暂不支持全自动提交。脚本会尝试填入答案，请手动检查并点击提交。
