# DGUT 优学院助手

东莞理工学院优学院平台的浏览器用户脚本。

学习功能：近七天日程、视频倍速刷课、自动答题、题库导出、作业互评汇总、读书计时。
工具箱：Markdown 转 Word / PDF、Word 转 PDF、图片压缩处理、手绘电子签名。

文档和图片都在浏览器本地处理，不上传服务器。标准版已移除课程签到功能，请各位同学诚信签到打卡。

## 安装指南

1. 装一个用户脚本管理器扩展。
2. 在管理器中新建脚本，把本脚本完整代码粘贴进去。
3. 保存并确认启用。
4. 打开任意网页，右下角出现悬浮图标，点击展开面板。

面板在所有网页都能打开；日程、刷课等学习功能只在优学院相关页面生效。首次使用文档功能需要联网加载组件，之后有缓存。

## 使用说明

### 面板通用操作

- 点右下角悬浮球展开或收起面板。
- 按住顶部标题栏拖动，位置自动记忆。
- 拖丢了就在脚本管理器菜单里选「重置面板/悬浮面板位置」。
- 脚本管理器菜单为每个功能提供了直接跳转命令。

### 近七天日程

1. 打开视图即读取近 7 天日程，按时间升序平铺显示。
2. 活动日历接口不含考试，脚本按「课程 → 考试列表」额外读取，未结束的考试最多看 120 天；读取失败只在状态栏提示一句。
3. 点复选框标记完成并置灰，勾选状态只存本地。
4. 过期的项自动移除，不提醒不弹窗。
5. 拉取成功后缓存一份，不在优学院页面或未登录时也能先看上次的。
6. 点「刷新」手动重新拉取。

### 刷课助手

1. 设置视频倍速（默认 6 倍，范围 1-16，建议 6-10）、自动答题、自动翻页、题库收集。
2. 点「启动」，按设定倍速播放，遇到题目尝试作答，看完自动翻页。
3. 点「导出题库」生成 Word 文档；「清空题库」清除本地缓存（不可恢复）。

平台把倍速改回去时脚本会自动再设一次；未知题型跳过，不会盲点。

### 作业互评

1. 进入互评详情页自动扫描，还原评价人姓名与班级并在页面标注。
2. 记录以卡片展示评价人、分数、评语、班级与时间。
3. 支持按姓名 / 学号搜索，按分数区间筛选（写法如 `80-95`、`>90`、`<80`）。

### 求是读书

1. 点「开始」按书目累计时长，默认不会自动开始。
2. 翻页间隔默认 30 秒 / 页，保存后同步给页面内的阅读器。
3. 本地时间与服务端时间互相对齐。
4. 服务端时长满 4 小时 10 分后自动翻页并切下一本，全部读完会提示。

### 文档工具

1. 输入 Markdown，支持标题、粗体、列表、代码块、表格、引用等常用语法，自动保存草稿。
2. 点「预览」查看渲染效果。
3. 「导出 Word」生成 `.doc`，Word / WPS 可直接打开编辑。
4. 「下载 PDF」本地生成 A4 多页 PDF 直接保存，不过打印对话框，大文档需要几秒。
5. 「打印 PDF」打开打印视图后选「另存为 PDF」，文字为矢量、体积更小。
6. 手绘电子签名：在画板上写（鼠标 / 触屏 / 触控笔），填标签保存，可存多份；勾选的签名附加到导出文档末尾，可随时删除或重画。

### Word 转 PDF

1. 选择 `.docx` 文件（Word 2007 及以上；旧版 `.doc` 请先另存为 `.docx`）。
2. 选择文件后自动解析并预览。
3. 三种输出：下载 PDF、打印 PDF、导出为 .doc。

复杂排版、特殊字体或表格可能出现样式偏差或分页不理想，这是已知限制。

### 图片工具

1. 载入 JPG / PNG / WebP 等常见格式，也可以直接把图拖进来。
2. 缩放：不缩放、按百分比、按像素尺寸；适配方式支持包含、覆盖、拉伸。
3. 平滑：高质量（推荐，减少毛糙、锯齿和摩尔纹）、标准、关闭（适合像素风）。
4. 图像处理：锐化、灰度（不是二值化）、亮度均匀。
5. 输出：保持原格式或转 JPEG / PNG / WebP；可压缩到目标大小，或增大到指定大小。
6. 先「预览效果」确认，再「处理并下载」。

### 外观设置

- 主题模式：亮色 / 暗色 / 跟随系统。
- 主体色：紫罗兰、蔚蓝、松石、青绿、琥珀、玫红六种预设，也可用取色器自定义。
- 设置自动保存并立即生效。

## 主题美化扩展（可选）

美化包只换外观，不动功能，不装也能正常用。文件：`小助手UI主题美化扩展-纳西妲主题.js`。

先装好主脚本，再用同样的方式新建脚本、粘贴代码、保存启用，展开面板即可看到纳西妲主题。

停用或删除美化包，界面就恢复默认外观。主脚本大改界面结构时，美化包可能需要一并更新。

## 数据与隐私

文档内容、图片、签名全部在浏览器本地处理，不上传服务器。配置、题库、日程缓存与勾选状态、互评记录、签名保存在脚本管理器存储和浏览器本地存储中。清除浏览器数据或重装脚本管理器会丢失，重要内容请及时导出。

## 常见问题

**Q: 签到功能去哪了？**
A: 标准版已移除，请走学校官方渠道诚信签到。

**Q: 日程可以手动添加吗？**
A: 不能。只读显示近 7 天事项与未来考试，不手工导入、不分类、不带提醒。

**Q: 刷课倍速设置后没有生效？**
A: v5.13.5 已修复，更新后刷新课件页即可。先确认点了「启动」，倍速只在刷课运行时生效；还是不行就打开「详细调试日志」，把里面「倍速」的几行发给我。

**Q: 自动答题会盲点吗？**
A: 不会。未知题型一律跳过，取不到答案就不作答。

**Q: PDF 直接下载和打印 PDF 有什么区别？**
A: 「下载 PDF」直接保存，不走打印对话框，体积可能稍大；「打印 PDF」走打印视图另存，文字为矢量、体积更小。

**Q: 图片压缩后为什么显得毛糙？**
A: 把「平滑」设为「高质量」，降低锐化强度或关闭锐化；压缩比过大时勾选「允许降低分辨率」，画质更自然。

**Q: 签名会丢失吗？**
A: 签名存在本地存储中，清除浏览器数据或更换设备会丢失，重要签名建议导出到文档后另行保存。

**Q: 面板被拖到屏幕外找不到了？**
A: 脚本管理器菜单里选「重置面板/悬浮面板位置」。

**Q: 为什么所有网站都会出现悬浮球？**
A: 面板设计为全站可用，方便随时用文档、图片工具；日程、刷课只在优学院相关页面生效。

**Q: 首次使用文档功能为什么需要联网？**
A: 要加载文档处理组件，加载一次后有缓存。

**Q: 美化包会影响功能、可以不装吗？**
A: 可以不装，主脚本默认界面功能完整。美化包只改配色、背景、描边、粒子等外观，随时停用即恢复。

**Q: 美化包安装后没有生效？**
A: 依次确认主脚本已启用、美化包已保存启用，必要时在美化包菜单里确认「切换面板背景」处于「开」。
