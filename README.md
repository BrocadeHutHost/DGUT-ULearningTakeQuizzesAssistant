# DGUT 优学院助手 + 文档工具 Ciallo～(∠・ω< )⌒★

> 一个专为东莞理工学院（DGUT）优学院平台编写的浏览器用户脚本。
>
> 学习功能：**近七天日程、视频倍速刷课、自动答题、题库导出、作业互评汇总、读书计时**。
> （因部分原因，标准版已移除课程签到功能，请各位同学诚信签到打卡。）
> 附加工具：**Markdown 转 Word / PDF、Word 转 PDF、图片压缩处理、手绘电子签名**。
>
> 所有文档与图片处理均在浏览器本地完成，内容不上传任何服务器。

## 安装指南

1. **安装用户脚本管理器**
   在你的浏览器扩展商店中，任选一款支持「用户脚本（userscript）」的管理器扩展安装即可，主流浏览器均有对应产品。
2. **添加脚本**
   在管理器中新建脚本，将本脚本的完整代码粘贴进去。
3. **保存并启用**
   保存后确认脚本处于启用状态。
4. **开始使用**
   打开任意网页，页面右下角会出现悬浮图标，点击即可展开操作面板。

> 说明：面板在所有网页都能打开（方便随时使用工具箱），但日程、刷课等学习功能需要在优学院或 DGUT 相关页面才生效。首次使用文档相关功能时需要联网加载依赖库，之后有缓存。
>
> 说明：以上步骤安装的是**主脚本**，其界面已完整可用，**普通用户无需额外安装任何美化包**。若你希望更换界面主题，请参见 [主题美化扩展（可选）](#主题美化扩展可选)。
>
> 说明：本仓库根目录下的 **`理工小助手.js`** 就是可直接安装的单文件脚本，复制粘贴它即可。
> 旁边那份 **`理工小助手.user.js`** 与它**内容完全相同**，只是多了 `.user.js` 后缀——
> 油猴只把 `.user.js` 结尾的链接识别成"可安装脚本"，面板里的「⬆ 立即更新」按钮要靠它才能弹出安装页。
> 本仓库只放可直接导入的单文件成品，不放开发用的拆分源码。

## 使用说明

### 面板通用操作

- **展开 / 收起**：点击右下角悬浮球展开面板，再次点击收起。
- **移动位置**：按住面板顶部标题栏拖动，位置自动记忆，下次打开保持在原处。
- **拖丢了怎么办**：通过脚本管理器中本脚本的菜单命令，选择「重置面板/悬浮面板位置」即可恢复默认位置。
- **快捷入口**：脚本管理器的菜单里为每个功能都提供了直接跳转命令，不用先展开面板。

### 近七天日程

> 说明：因部分原因，本脚本已**移除课程签到功能**（不再自动监测 / 自动提交签到），
> **请各位同学诚信签到打卡**，签到请走学校官方渠道。

进入优学院页面（`lms.dgut.edu.cn` / `ua.dgut.edu.cn`），打开面板中的「近七天日程」：

1. **自动读取**：打开视图即通过只读接口拉取近 7 天的日程，按时间升序平铺显示，不分类、不筛选。
2. **勾选置灰**：点任意一项的复选框即标记完成并置灰；勾选状态只保存在本地，刷新/重开不丢。
3. **过期自动清理**：过了截止时间的项会自动从列表移除（每分钟检查一次），不会提醒、不会弹窗。
4. **刷新**：点「刷新」可手动重新拉取（打开视图 5 分钟内复用缓存，避免频繁请求）。

**日程数据从哪来（接口获取逻辑）**：

```
GET https://lms.dgut.edu.cn/courseapi/activitycalendar
    ?startDate=YYYY-MM-DD        // 今天
    &endDate=YYYY-MM-DD          // 今天 + 7 天
    &lang=zh
请求头：Authorization: <当前登录 token>（原样，不加 Bearer；只读 GET，anonymous）
返回：{ total, courseCount, homeworkCount, …, activityList: [
        { activityId, activityType, title, ocId, courseName, beginTime, endTime } ] }
```

- `beginTime` / `endTime` 是**毫秒时间戳**；脚本只保留「截止时间在 7 天内且未过期」的项，
  按时间升序排列，显示「开始 / 截止 + 标题 + 课程名」。
- 该接口是**唯一带时间范围的只读日程接口**；课堂接口（`getClassroomList` /
  `classroomActivitys`）没有时间范围参数，因此没有用于日程。
- 只发只读 GET，不写任何服务端状态；接口字段若调整，界面会显示「读取日程失败」并附带原文。

### 刷课助手

进入包含视频的课件页（地址含 `ua.dgut.edu.cn/learnCourse`），打开面板中的「刷课助手」：

1. **设置参数**：视频倍速（默认 6 倍， 范围 1-16 ， 建议 6-10）、是否自动答题、是否自动翻页、是否收集题库。
2. **启动**：点击「启动」，脚本自动以设定倍速播放视频，遇到题目时尝试作答，看完自动翻页。
3. **导出题库**：答题过程中题目与答案自动缓存到本地；点击「导出题库」生成 Word 文档用于复习。
4. **清空题库**：点击「清空题库」清除本地缓存（不可恢复）。

工作方式说明：

- **倍速守卫**：平台把倍速改回去时，脚本会立刻改回设定值，并学习平台的重置频率来调整检查间隔。
  已适配媒体播放器在每次 `loadedmetadata` 时把倍速重置回 1.00× 的行为（`ratechange` /
  `loadedmetadata` / `canplay` / `playing` 四个事件 + 周期检查一起兜底），设置后即使被重置也会立即改回。
- **答案来源顺序**：页面视图模型、本地题库、答案接口，依次尝试；**未知题型一律跳过、绝不盲点**（平台测验多为限答 1 次）。
- **防移除保护**：内置机制防止播放器被页面脚本意外移除。
- **弹窗处理**：自动关闭答题统计等弹窗，不打断流程。

### 作业互评

进入作业互评详情页（网址含 `stuDetail/学号/作业ID`），打开面板中的「作业互评」：

1. **扫描当前作业**：点击后读取互评接口，还原评价人的姓名与班级（去匿名化），并在页面上直接标注「评价人 / 待评价人」。
2. **查看记录**：以卡片形式展示评价人、分数、评语、班级与时间。
3. **筛选**：按姓名 / 学号搜索，或按分数区间筛选（写法如 `80-95`、`>90`、`<80`）。
4. **清空记录**：清除本地保存的全部互评记录。

### 求是读书

进入求是读书课件页（地址含 `ua.dgut.edu.cn/learnCourse/learnCourse.html`），打开面板中的「求是读书」：

1. **开始 / 暂停**：开始后按书目累计阅读时长；暂停则停止统计。**默认不会自动开始**
   （只有你主动点过「开始」并且没有点「暂停」时，下次打开阅读页才会自动恢复）。
2. **翻页间隔**：设置自动翻页的秒数（默认 30 秒 / 页），保存后会同步给页面内的阅读器。
3. **同步服务端**：把服务端记录的时长同步到本地，两边数据对齐。
4. **自动切书**：累计满 4 小时 10 分钟后自动翻页并切换下一本书，全部读完会提示。

### 文档工具

打开面板中的「文档工具」：

1. **输入 Markdown**：在文本区输入内容，支持标题、粗体、列表、代码块、表格、引用等常用语法；内容自动保存草稿，重开不丢。
2. **预览**：点击「预览」实时查看渲染效果。
3. **导出 Word**：生成 `.doc` 文件，Word / WPS 可直接打开与二次编辑。
4. **下载 PDF**：本地生成 A4 多页 PDF 并直接保存，**不需要经过打印对话框**。生成需要几秒，大文档稍长。
5. **打印 PDF**：打开打印视图，在打印对话框中选择「另存为 PDF」。文字为矢量、体积更小，适合对清晰度要求高的场景。
6. **手绘电子签名**：
   - 在画板上手写（支持鼠标 / 触屏 / 触控笔）；
   - 填写标签（如「本人签名」「导师签字」）后保存，可保存多份；
   - 勾选的签名会附加到导出文档末尾，以透明 PNG 嵌入；
   - 可随时删除或重画。

### Word 转 PDF

打开面板中的「Word 转 PDF」：

1. 选择 `.docx` 文件（Word 2007 及以上格式；旧版 `.doc` 请先另存为 `.docx`）。
2. 可选三种输出：**下载 PDF**（本地直出，无需打印对话框）、**打印 PDF**（矢量文字）、**导出为 .doc**（可继续编辑）。
3. 选择文件后自动解析并预览内容。

> 注意：复杂排版、特殊字体或表格可能出现样式偏差或分页不理想，属已知限制，后续版本持续优化。首次使用需联网加载解析库（自动从 CDN 获取，有备用源）。

### 图片工具

打开面板中的「照片处理」：

1. **选择图片**：载入 JPG / PNG / WebP 等常见格式。
2. **缩放**：不缩放、按百分比、或按像素尺寸（可选 1:1、4:3、16:9 等比例预设，宽高自动联动）；适配方式支持「包含（留边）」「覆盖（裁剪）」「拉伸（填满）」。
3. **平滑**：
   - 高质量（推荐）：缩小时先逐级减半再插值，显著减少压缩后的毛糙、锯齿和摩尔纹；
   - 标准：浏览器默认插值；
   - 关闭：适合像素风或需要硬边的场景。
4. **图像处理**：锐化（强度可调）、黑白（阈值可调）、亮度均匀（直方图均衡，改善曝光不均）。像素运算在后台多线程执行，不卡界面。
5. **输出**：
   - 格式：保持原格式，或转为 JPEG / PNG / WebP；
   - 压缩到目标大小：填 KB 数后自动调节质量逼近目标，仍不够小时可勾选「允许降低分辨率」逐步缩小；
   - 增大到：在文件末尾追加填充数据到指定大小（随机或全零字节）。
6. **预览与下载**：先「预览效果」确认，再「处理并下载」保存。

## 常见问题 (FAQ)

**Q: 签到功能去哪了？**
A: 因部分原因，标准版已移除课程签到（自动监测 / 自动提交）功能，请各位同学诚信签到打卡，签到请走学校官方渠道。完整版（不公开分发）仍保留该功能，但同样建议以官方签到为准。

**Q: 日程数据从哪来？可以手动加吗？**
A: 只读优学院活动日历接口 `GET /courseapi/activitycalendar?startDate=&endDate=&lang=zh`（近 7 天），不手工导入、不分类、不带提醒；勾选状态与过期清理都只在本地完成。接口需要登录态，因此请在优学院页面打开日程。

**Q: 刷课倍速设置后没有生效？**
A: 先确认已点击「启动」——**倍速守卫只在刷课助手运行中生效**。若启动后仍不变速：
v5.9.2 之前的版本在部分浏览器（如 Edge + 油猴沙箱）里可能因跨 realm / 沙箱包装导致
「读取或写入播放速率」不落到真实媒体上，于是静默跳过设置（面板显示 6×、视频仍是 1×，日志无报错），
请更新到 **v5.9.2 或更高版本**，并**刷新课件页**后再试。
更新后打开「🔍 详细调试日志」，〔判定〕行会打印 `rate=实际值x(目标 Nx)`，可一眼看出倍速是否真的落到视频上；
运行日志里出现「倍速守卫：把播放速率重设为 Nx」说明守卫正在纠偏；
若出现「页面世界读回…（已用页面世界句柄修正）」，说明 v5.9.2 的兜底路径正在生效。
另外平台在每次视频加载（`loadedmetadata`）时都会把倍速重置回 1.00×，守卫会立即改回设定值，属正常现象。

**Q: 自动答题会盲点吗？**
A: 不会。未知题型一律跳过；答案依次取自页面视图模型、本地题库、答案接口，取不到就不作答。

**Q: PDF 直接下载和打印 PDF 有什么区别？**
A: 「下载 PDF」本地生成后直接保存，不走打印对话框，但属于图片式渲染，体积可能稍大；「打印 PDF」走打印视图另存，文字为矢量、体积更小。Word 转 PDF 的样式还原度目前有限，后续会优化。

**Q: 图片压缩后为什么显得毛糙？**
A: 把「平滑」设为「高质量」，并降低锐化强度或关闭锐化；压缩比过大时勾选「允许降低分辨率」让脚本逐步缩小尺寸，画质更自然。

**Q: 签名会丢失吗？**
A: 签名保存在本地存储中，清除浏览器数据或更换设备会丢失，重要签名建议导出到文档后另行保存。

**Q: 面板被拖到屏幕外找不到了？**
A: 在脚本管理器中本脚本的菜单命令里选择「重置面板/悬浮面板位置」，即可恢复默认位置。

**Q: 为什么所有网站都会出现悬浮球？**
A: 面板设计为全站可用，方便随时使用文档、图片等工具；日程、刷课等功能则只在优学院相关页面生效。

**Q: 首次使用文档相关功能为什么需要联网？**
A: 需要从 CDN 加载渲染与导出依赖库（有备用源与兜底通道），加载一次后有缓存，之后离线也能用已加载过的功能。

**Q: 我不想要美化包可以不安装吗？**
A: **可以！**。主脚本默认界面功能完整、开箱即用；美化包仅在你想要主题皮肤时才安装，属于可选外观。

**Q: 安装了美化包会不会影响功能？**
A: 不会。美化包只改变配色、背景、描边、粒子等外观，不改动功能逻辑；可随时停用以恢复默认外观。

**Q: 美化包安装后没有生效？**
A: 请依次确认：① 主脚本已安装并启用；② 美化包已保存并启用；③ 打开面板查看，必要时在美化包菜单中确认「切换面板背景」处于「开」。
